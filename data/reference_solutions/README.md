# IHTC-2024 reference best solutions (snapshot 2026-07-06)

The 30 files `sol_i01.json .. sol_i30.json` are the competition's **published best public-dataset
solutions**, downloaded from https://ihtc2024.github.io/assets/files/solutions/public/ on
**2026-07-06**. They are stored here so the comparison baseline is fixed and auditable. All 30 re-
score under the official validator to exactly the best-known values snapshotted in
`../best_known_ihtc2024.csv`, with zero violations. They are the competition's solutions, not ours,
and are used only
as a reference baseline, never as an input to our solver.
